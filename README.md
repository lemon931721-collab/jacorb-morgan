# Portfolio Template

A clean, responsive developer portfolio inspired by the general layout and presentation style of modern personal developer portfolios.

## Files

- `index.html` — portfolio structure/content
- `style.css` — styling and responsive layout
- `script.js` — tabs, mobile menu, reveal animations
- `assets/` — add your profile and project images here

## Customize

Search for:

- `YOUR NAME`
- `you@example.com`
- `YOUR_USERNAME`
- `Your Company`
- `Your University`

Replace those values with your information.

Add images as:

- `assets/profile.jpg`
- `assets/project-1.jpg`
- `assets/project-2.jpg`
- `assets/project-3.jpg`
- `assets/project-4.jpg`

The page will fall back to emoji placeholders if images are missing.

## Run locally

Open `index.html` in a browser, or serve the folder with any simple local web server.

## GitHub Pages

Upload the files to a GitHub repository and enable GitHub Pages from the repository's Pages settings.
